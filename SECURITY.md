# Security reporting

Please report suspected vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/28allday/omaraw/security/advisories/new).
Do not attach sensitive photographs, credentials or a personal catalog to a
public issue. Include the affected version, reproduction steps and the impact.
If private reporting is unavailable, open an issue requesting a private contact
without disclosing exploit details or private files.

Use supported, updated Arch packages for system libraries. Releases include a
matching source bundle and checksums. Beta packages are currently unsigned.

Photo editing runs locally. Optional model installation downloads tools and
models after you request it. Opening an external link uses your browser.
