# Digital cinema tables

The eight `tables/*-digital.ompt` files are generated by OmaRAW's GPL-3.0-or-later
`tools/film/digital_film.py`. They use the extracted characteristic curves and
spectral data already documented in each stock's `SOURCE.md`. Kodak 2383 uses
the corrected characteristic curves in `kodak-2383-v3`; the four Fuji stocks
retain the documented Kodak dye substitutes. No third-party film LUT values
are copied, fitted, or required at runtime.

The Cineon input conversion uses full-range CV95 black / CV685 at linear 1.0.
Kodak H-387's intermediate-negative calibration supplies the CV445 reference
and .002 density per code. The existing stock-specific Status A aims remain
the characteristic-curve calibration points. Display mapping independently
sets the upper Cineon code to white and the LAD patch to luminance .1, retains
midtone colour, and maps out-of-gamut values by reducing chroma at fixed
luminance. This is a digital look with explicit assumptions, not a measured
physical-film match.

`tables/digital-film.json` records the display anchors, spectral substitutes,
and maximum adjustment used to remove small digitisation reversals in each
characteristic curve. Source CSVs are not modified. Rebuild all eight tables:

```sh
python tools/film/digital_film.py --out data/film/tables
```

The developer environment requires NumPy and colour-science; the application
only reads the generated tables. It needs no Python environment, model, network
service, or particular GPU for this workflow. Kodak documents/charts and the
user-supplied comparison LUTs are private test inputs and are not redistributed.
